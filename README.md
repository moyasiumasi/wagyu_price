# Git Lesson

## リモートリポジトリとローカルリポジトリとそれぞれ何でしょうか？

+ リモートリポジトリとは、ネットワーク上のサーバーなどに配置され、チーム（開発者同士）で共有するためのリポジトリのことです。
+ ローカルリポジトリとは、個人開発環境に作成された個人の作業スペースです。
+ リポジトリとは、データやファイルなどを保管・管理する場所のこと

## プッシュとマージの違いは何でしょうか？

+ プッシュは、ローカルリポジトリの変化をリモートリポジトリにアップロードするこです。
+ マージは、あるブランチの変更を他のブランチにも統合することです。
+ プッシュは変化を共有、マージは変化を統合するという違いがあります

## コミットとプッシュの違い

+ コミットは、ファイル追加や変更の履歴をリポジトリに記録することです。
+ プッシュは、ファイル追加や変更の履歴をリモートリポジトリにアップ（反映）する操作のことです。
+ コミットは自分にだけ保存。プッシュはネットにアップして保存

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

+ コミットの主な変更点を簡易に記述する。
+ 件名だけでは分かりにくい場合は、変更理由や変更の背景、意図を記述しておく。

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

+ ローカルでマージするフローは、個人でマージまでしてしまうのでコードミスやバグがあっても見落とし安い。
+ プルリクエストでマージするフローは、変更内容をチームリーダーなどに確認してもらいリモートリポジトリにマージしてもらうことでコードミスやバグが事前に発見しやすい。

## コンフリクトを起こしてしまった場合、どのように対処すべきですか？

+ git revert（リセット）を使って、コンフリクト（競合）しているファイルをリセットをする。ただし、resetしたというログもgit logに残るので注意！
+ コンフリクト＝競合：ブランチをマージする際に両方のブランチで同じ箇所を変更している場合に起こる現象
